💡 How to use example files
📋 Visualizer

Download any file → go to SOC/SIEM Rules → Visualizer → upload it → see all rules as structured cards with severity, tactics, and detection logic.

⚖️ Comparator

Download two files (e.g. Sigma + Elastic) → go to SOC/SIEM Rules → Comparator → upload both → see common rules, differences, and coverage gaps.

🔗 Correlation

Download any file → go to Rule Correlation → upload it → pick scan mode → run analysis → explore the interactive graph.
